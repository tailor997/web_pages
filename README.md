# LC谐振频率计算器

一个用于计算LC并联电路谐振频率的网页应用。

## 功能介绍

- **电容配置**：支持添加多个并联电容（最多4个）
- **电感配置**：支持预设或自定义电感值
- **实时计算**：根据输入的电容和电感值计算谐振频率
- **直观显示**：清晰展示总电容值和谐振频率结果

## 使用方法

1. **配置电容**：
   - 默认提供一个电容配置，可点击"添加电容"按钮添加更多（最多4个）
   - 每个电容可选择预设值（E12系列）或自定义值
   - 自定义值支持pF、nF、uF、mF、F等单位

2. **配置电感**：
   - 可选择预设电感值或输入自定义值
   - 支持nH、uH、mH、H等单位

3. **计算结果**：
   - 点击"计算谐振频率"按钮
   - 查看总电容值和谐振频率结果

## 公式

谐振频率计算公式：
```
f = 1/(2π√(L*C))
```

其中：
- f：谐振频率（Hz）
- L：电感值（H）
- C：总电容值（F）
